# SUIKA DELUXE

すいかゲーム風の物理マージパズルゲーム(ブラウザ / GitHub Pages)。

## 特徴
- 全15段階のフルーツ(さくらんぼ 〜 すいか 〜 小さな星・月・太陽・銀河)
- Matter.js による本格物理演算
- 実績100種類以上(スコア・マージ回数・プレイ回数・プレイ時間・特殊条件など)
- フルーツスキン5種、背景8種(条件達成で解放)
- 統計・更新履歴パネル
- ローカルストレージによる進行状況の自動保存

## 遊び方
クリック / タップ / スペースキーでフルーツを落とし、同じフルーツ同士をぶつけて合体させる。
より大きなフルーツを作りスコアを稼ごう。すいかを超えた先には何があるか、実際に確かめてみよう。

## 技術構成
- Vanilla JS + [Matter.js](https://brm.io/matter-js/)(CDN読み込み、ビルド不要)
- `js/data.js` フルーツ/スキン/背景の定義
- `js/achievements.js` 実績定義(100種類以上)
- `js/storage.js` localStorage 保存
- `js/game.js` ゲームロジック・物理演算
- `js/ui.js` モーダル・パネルのDOM制御
- `js/version.js` 更新履歴
